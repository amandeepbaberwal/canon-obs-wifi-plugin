# Changelog

## [0.1.0] - 2026-07-07

First public source release.

### Added

- Canon EOS Wi-Fi Live View bridge over PTP/IP.
- Local MJPEG stream at `/live.mjpg` for OBS Browser Source.
- Operator dashboard, `/health`, `/status.json`, and `/snapshot.jpg` endpoints.
- Canon EOS Rebel T100 / EOS 4000D hardware contract at `480x320`.
- Reconnection without resetting, disabling, or rewriting Windows Wi-Fi state.
- SSDP/UPnP discovery and PTP/IP probe modes.
- CLI interface listing, discovery, describe, probe-only, MTP smoke, and serve.
